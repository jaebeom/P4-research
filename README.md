# P4-research

ROKEY 9기 **P4 프로젝트**를 위한 **조사 자료** 모음이다.
프로젝트 본체(요구사항 문서, 설계, 코드, 과제)는 별도 저장소 `ROKEY_P4`(비공개)에 있고, 이 저장소에는 그 문서들의 **근거가 되는 조사**만 둔다.

## 폴더

| 폴더 | 내용 |
|---|---|
| [`notes/`](notes/README.md) | 조사 노트. 한 주제에 파일 하나, 파일명에 날짜를 붙인다 (`YYYY-MM-DD-주제.md`) |
| [`topics/`](topics/README.md) | P4 주제 후보 조사와 비교표 (주제가 정해질 때까지 후보를 모은다) |

## 노트를 쓸 때 지킬 것

이 저장소는 **공개**다. 올리기 전에 확인한다.

1. **숫자에는 출처와 확인한 날짜를 붙인다.** 직접 계산하거나 추정한 값은 "추정"이라고 쓰고 계산식을 남긴다.
2. 확인하지 못한 것은 **"미확인"** 으로 적는다. 그럴듯한 숫자를 지어내지 않는다.
3. 로봇 IP 같은 환경 정보, 비밀번호, 토큰, 개인 정보, 사람이 나온 사진은 올리지 않는다.
4. 강의 자료와 다른 사람의 코드를 **그대로 옮기지 않는다.** 요약과 링크만 쓴다. 라이선스가 없는 코드는 구조 설명만 한다.
5. 노트의 첫 줄 결론은 한 문장으로, 근거는 표로 쓴다 ([템플릿](notes/_template.md)).

## 작업 방식

브랜치 `research/<주제>`에서 작성하고 PR로 `main`에 합친다. PR 체크리스트는 [`.github/pull_request_template.md`](.github/pull_request_template.md)에 있다.

## 관련 저장소

- `ROKEY_P4` (비공개): 요구사항(BRD/SRD), 설계, 코드, 과제
- 강사 자료: https://github.com/kimandreas/to_students

## 라이선스

아직 정하지 않았다 (지금은 별도 표시가 없으면 모든 권리가 작성자에게 있다). 다른 사람이 가져다 쓰게 하려면 라이선스를 추가한다.
